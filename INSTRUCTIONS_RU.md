# Инструкция по использованию JamRTC

## Что это такое?

JamRTC - это веб-приложение для потоковой передачи MIDI-данных в реальном времени между двумя пользователями через WebRTC. Используйте его для совместной игры на MIDI-клавиатурах через интернет!

## Быстрый старт для denizsincar.ru/midi

### 1. Первый музыкант (создаёт комнату)

1. **Сначала подключите MIDI-клавиатуру** к компьютеру
2. Откройте сайт: https://denizsincar.ru/midi
3. В поле "Room Name" введите название комнаты (например, "jam-session-1")
4. Нажмите кнопку "Подключиться к комнате"
5. Разрешите доступ к MIDI-устройствам, когда браузер попросит
6. Скопируйте URL-адрес, который появится (например: https://denizsincar.ru/midi/?room=jam-session-1)
7. Отправьте этот URL второму музыканту (через WhatsApp, Telegram и т.д.)

### 2. Второй музыкант (присоединяется к комнате)

1. **Сначала подключите MIDI-клавиатуру** к компьютеру
2. Откройте URL, который вам отправил первый музыкант
3. Разрешите доступ к MIDI-устройствам
4. Дождитесь сообщения "Подключено" (Connected)
5. Готово! Теперь можно играть вместе

### 3. Настройка устройств

В разделе "MIDI Devices":
- **Input Device** (Входное устройство): выберите вашу MIDI-клавиатуру (с неё вы будете играть)
- **Output Device** (Выходное устройство): выберите виртуальное MIDI-устройство или синтезатор (на нём будут воспроизводиться ноты от другого музыканта)

### 4. Начинайте играть!

Когда оба музыканта подключены:
- Ноты, которые вы играете, будут передаваться второму музыканту в реальном времени
- Вы будете слышать ноты, которые играет второй музыкант
- Задержка обычно составляет 20-100 миллисекунд
- Вкладка браузера может работать в фоновом режиме

## Требования

- Современный браузер с поддержкой Web MIDI API:
  - **Google Chrome** (рекомендуется)
  - **Microsoft Edge**
  - **Opera**
  - **Firefox** (автоматически скачает MIDI-компонент при первом использовании)
- MIDI-клавиатура или контроллер, подключённый к компьютеру
- Стабильное интернет-соединение

## Дополнительные настройки

### Базовые настройки (раздел Settings)

- **Language**: Выбор языка интерфейса (English / Русский)
- **Enable SysEx Support**: Разрешить System Exclusive сообщения (нужно для расширенных функций клавиатуры)
- **Enable Timestamp Sync**: Экспериментальная функция для улучшения синхронизации при медленном соединении
- **Show MIDI Activity**: Показывать MIDI-события в реальном времени
- **Enable IPv6 P2P**: Попытка соединения через IPv6 (по умолчанию включено)

### Отладочные инструменты (Debug Tools)

- **Send Test Note (C4)**: Отправить тестовую ноту для проверки соединения
- **Send Ping**: Проверить задержку соединения
- **MIDI Echo**: Отправлять обратно все полученные MIDI-сообщения (для тестирования)

## Устранение неполадок

### Проблемы с подключением

- **Долгое ожидание подключения**: WebRTC может требовать 5-10 секунд. Подождите немного.
- **Не удаётся подключиться**: 
  - Убедитесь, что оба пользователя используют один и тот же URL с правильным названием комнаты
  - Проверьте подключение к интернету
  - Попробуйте перезагрузить страницу
  - Проверьте, не блокирует ли брандмауэр WebRTC соединения

### Проблемы с MIDI

- **MIDI-доступ запрещён**: 
  - Убедитесь, что вы используете поддерживаемый браузер
  - MIDI-устройство должно быть подключено ДО открытия сайта
  - В Firefox разрешите автоматическую загрузку MIDI-компонента
- **Нет звука**: Проверьте выбор выходного MIDI-устройства и подключение к колонкам/наушникам
- **Устройства не отображаются**: Нажмите кнопку "Refresh Devices" или переподключите MIDI-устройство
- **Высокая задержка**: Может указывать на использование TURN-релея вместо прямого P2P-соединения

### Ошибки при подключении

Если вы видите ошибку при подключении:
- Проверьте правильность названия комнаты
- Убедитесь, что оба участника используют одинаковый URL
- Попробуйте создать новую комнату с другим названием
- Проверьте настройки брандмауэра

## Советы для лучшего опыта

1. **Подключайте MIDI-клавиатуру первой**: Всегда подключайте устройство ДО открытия сайта
2. **Используйте проводное соединение**: Wi-Fi может добавлять задержку
3. **Закройте ненужные приложения**: Освободите системные ресурсы
4. **Проверьте задержку**: Используйте кнопку "Send Ping" для проверки скорости соединения
5. **Настройте буферизацию**: Если слышны разрывы звука, попробуйте включить "Enable Timestamp Sync"
6. **Сохраните URL комнаты**: Добавьте в закладки URL с названием комнаты для быстрого доступа

## Безопасность и приватность

- Все MIDI-данные передаются напрямую между участниками (P2P) через зашифрованное WebRTC-соединение
- Сервер signaling только помогает установить соединение и не видит ваших MIDI-данных
- Не передаются никакие личные данные, кроме необходимых для WebRTC

## Поддержка

Если у вас возникли проблемы:
1. Нажмите кнопку "Справка" (Help) в верхней части страницы для просмотра пошаговых инструкций
2. Убедитесь, что оба участника используют последнюю версию приложения
3. Попробуйте использовать другой браузер (рекомендуется Chrome)
4. Сообщите о проблеме на GitHub: https://github.com/denizsincar29/web_jamrtc
