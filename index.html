      Settings

      Allow System Exclusive messages (required for advanced keyboard features)

      Send MIDI data with timestamps for better timing on slow connections

      Display and announce MIDI events via screen reader

      Attempt IPv6 connections for peer-to-peer communication. If disabled, only IPv4 will be used.

      Uses an unordered, no-retransmit DataChannel (unreliable) to minimise jitter. Reconnect after toggling. Packet loss is expected — stuck notes are handled automatically.

      Lets you hear remote players even without a MIDI output device (e.g. on iPhone). Uses the built-in browser piano.

      When off, CC messages (mod wheel, expression, etc.) are not sent. Sustain, sostenuto and soft pedals are always sent.
